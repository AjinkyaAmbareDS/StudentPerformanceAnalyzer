STUDENTIQ — STUDENT PERFORMANCE ANALYZER

QUICK START:
1. Extract this ZIP to a folder.
2. Double-click index.html to open the website in Chrome or another browser.
3. Login using the demo accounts below.

DEMO LOGINS:
Student: student@vsecc.com / student123
Teacher: teacher@vsecc.com / teacher123

FEATURES:
- Separate student and teacher dashboards
- Subject-wise marks chart, overall average, attendance, risk indicator
- Study insights and individual reports
- Teacher class overview and adding assessment marks
- Responsive layout for desktop and mobile

This is a front-end college-project prototype. Sample data and edits are saved in your browser
using localStorage. It does not use a secure backend/database, and the risk indicator is
rule-based rather than a trained AI model. Do not use real student data in this demo.
